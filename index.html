Run Locally on Windows (Port 4000):
  1. Start Docker Desktop for Windows until the engine status is running.
  2. Extract lango-ukrainian-docker-port-4000.zip into a local folder.
  3. Open PowerShell in that folder and run: 
    docker compose up --build -d
  4. Open http://localhost:4000 in your browser.
